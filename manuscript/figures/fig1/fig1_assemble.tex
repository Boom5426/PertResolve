% Placement rules enforced here:
%   * every panel is placed at exactly the width it was drawn at, so its
%     internal 5-7 pt type is 5-7 pt ON THE PAGE. Every panel script writes its
%     declared millimetre canvas (nm_style.save(exact=True)), and
%     check_fig1_panels.py fails if a PDF is not that size, so no panel here
%     needs a corrective scale factor.
%   * rows are flush to the 183 mm page on both edges and sum to exactly 183:
%       row 1  113.5 + 3.5 + 66.0
%       row 2   58.0 + 4.5 + 69.0 + 4.5 + 47.0
%       row 3   78.0 + 5.0 + 100.0
%     Panel a is 113.5 mm, not the 122.5 mm it was first drawn at: at 122.5 the
%     row came to 188.5 mm before any gutter, and neither a nor b can be scaled
%     down at placement time because both bottom out at 5.0 pt type.
%   * one gutter value per row; 2.6 mm between rows, which is what the 8 pt
%     panel letter occupies. The row gap is set by the letter, not by taste:
%     any larger and the float exceeds the manuscript text height.
%   * rows share a common top edge; panel letters are lowercase bold 8 pt
%     (Nature Methods), placed 2.8 mm above each row's top edge.
% Page envelope 183 x 163.0 mm.
