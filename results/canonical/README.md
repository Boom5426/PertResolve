# Canonical result tables

Small, committed tables that back the main-figure and Supplementary-table numbers, so
every headline value regenerates from a tracked file. The figure scripts read these via
`manuscript/figures/remote_data.py` (`REM = results/canonical`). Previously these lived
under `results/_remote/unified/` (gitignored); they are promoted here for reproducibility.

Convention note: PDS has two documented conventions. The **multi-seed** convention (these
tables) is what the main text reports (PDS 0.49-0.52, all CIs overlap 0.50). The
**single-draw** grid (`results/results_v4_10metrics.csv`, `results/bootstrap_CIs.json`,
and the ESM2/AlphaMissense grid `results/reviewer_controls/rep_grid_summary.csv` plus
`am_summary.csv`) gives lower values (~0.46) and backs the Supplementary Table 7 single-draw
column. The representation grid was re-run on 2026-07-30 with all six regression heads after a
positional-argument defect was found to have silently dropped the MLP head; see
`results/reviewer_controls/README.md` and `results/deprecated/README.md`. The new range is
PDS-cosine 0.458--0.473 and Pearson-delta 0.628--0.659 over nine representations.

`best_model_pds.csv` is regenerated by `remote_data.best_model()` (max over the 18 in-house
heads of the per-gene mean PDS_cos in `unified_results5.csv`); the CSV is the pinned copy.

The three `residual_axis_*.csv` files were regenerated on 2026-08-04 by
`scripts/analysis/residual_axis.py` after a scoring defect was found. scVIDR's JAK1
predictions are non-finite; the unguarded ranking function returned `1 + 0.5/(n_g-1)` = 1.020
for each of that gene's 26 variants, a value above the metric's range, which had put scVIDR at
PDS 0.540 and residual-PDS 0.557. Non-finite predictions are now refused, counted
(`n_nonfinite`, `n_refused`) and reported, and scVIDR is scored on the 282 variants where it
produced a finite prediction: PDS 0.496, residual-PDS 0.514, i.e. at chance on both axes.
Every other method is bit-identical to the pre-fix run, and the ceiling file is unchanged
(it scores a second measurement, not a model prediction). Note that the multi-seed canonical
scorer uses a different convention for the same failure, assigning the chance value 0.5 to an
unscorable prediction; on that path scVIDR moves by +0.001 (0.504 to 0.505). The conventions
differ and are stated where each is used.

`pairwise_resolvability.csv` and `classifier_two_sample.csv` are computed on the curated
benchmark variant set (KRAS n=92, via the `allele_perturb_bench.csv` BENCH filter), matching
every other analysis; the plotted Fig 3g/3h values are unchanged from the pre-restriction run
(KRAS was already at the floor), so this is a traceability-consistency fix only.
