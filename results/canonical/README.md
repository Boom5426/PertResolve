# Canonical result tables

Small, committed tables that back the main-figure and Supplementary-table numbers, so
every headline value regenerates from a tracked file. The figure scripts read these via
`manuscript/figures/remote_data.py` (`REM = results/canonical`). Previously these lived
under `results/_remote/unified/` (gitignored); they are promoted here for reproducibility.

Convention note: PDS has two documented conventions. The **multi-seed** convention (these
tables) is what the main text reports (PDS 0.49-0.52, all CIs overlap 0.50). The
**single-draw** grid (`results/results_v4_10metrics.csv`, `results/bootstrap_CIs.json`,
and the ESM2/AlphaMissense grid `results/reviewer_controls/rep_grid_summary.csv`) gives
lower values (~0.46) and backs the Supplementary Table 7 single-draw column.

`best_model_pds.csv` is regenerated by `remote_data.best_model()` (max over the 18 in-house
heads of the per-gene mean PDS_cos in `unified_results5.csv`); the CSV is the pinned copy.

`pairwise_resolvability.csv` and `classifier_two_sample.csv` are computed on the curated
benchmark variant set (KRAS n=92, via the `allele_perturb_bench.csv` BENCH filter), matching
every other analysis; the plotted Fig 3g/3h values are unchanged from the pre-restriction run
(KRAS was already at the floor), so this is a traceability-consistency fix only.
