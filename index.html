PERTRESOLVE / OVERVIEWFigure 1

What a measurement can resolve is distinct from what a model predicts.

Resolution is evidence about the measurement, not a score assigned to a model.
The central question

Before comparing predictors, can the measurement reliably distinguish the response differences they are asked to predict?

01 / The approach

Separate the measurement
from the model.

PertResolve reports four empirical questions separately. Together, they show which biological distinctions are supported by the data and which model comparisons remain underdetermined.

03 / Use PertResolve

Your representation.
The same questions.

The public NumPy-first API measures a supplied expression matrix, embedding or other fixed representation using disjoint cell splits.

Turn a matrix and perturbation labels into a resolution report.

The report keeps detection, identification, split-half reproducibility and model-ranking resolution distinct. It does not manufacture a combined verdict.

Quick start ↗ Resolution API ↗ Benchmark data ↗

Python ≥ 3.10 · MIT License · Dataset-adaptable

resolution_report.py
import numpy as np
from pertresolve.resolution import resolution_report

with np.load("data/demo/pertresolve_resolution_demo.npz") as demo:
    X = demo["X"]
    labels = demo["labels"].astype(str)

report = resolution_report(
    X, labels,
    control="control",
    depth=8,
    n_seeds=4,
    seed=7,
)
print(report.summary())

Run python examples/run_resolution_demo.py after installation for the bundled, deterministic demo.
